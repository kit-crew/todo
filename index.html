Todo is not a task manager and not for recurring tasks. It's a one-time capture. List it, do it, check it off, and it's gone. Enter one or more tasks (one per line) and click + to add. Sections can be used to group tasks. Drag and drop to rearrange sections and tasks. Click to select a task; double-click to unselect it. Optional: Add a priority prefix and trailing time estimate in parentheses. Optional prefixes: A- through D-, numbered priorities such as A1-, !. Optional time estimates: at the end like (20).
